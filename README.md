# GTA: Underground patching library

A lightweight C++ tool designed to perform binary patches on legacy game engines by identifying specific hex patterns and injecting updated logic.
This is what I wrote long ago (2016/2017) and is what powered all of GTA: Underground's memory patching.

## Status
This repository is currently archived and thus I am not accepting any PRs or issues. The reason is simple; it does not stand up to my current programming & quality standards and the code is almost a decade old by now.
If you want to use it, consider using [LINK2012's injector](https://github.com/thelink2012/injector) instead.
